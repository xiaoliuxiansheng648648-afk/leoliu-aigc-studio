# LeoLiu Studio 1.0.5

2026-11-14。素材操作、专业编辑面板与首帧接戏优化。

## 更新内容

- 镜头卡的参考素材支持横向滚动和左右切换，方向键可滚动素材。
- 素材库与画布素材卡悬停时显示右上角删除按钮，仍被引用的素材会提示先移除引用。删除失败时恢复素材。
- 顶栏增加“简单 / 专业”切换。两种模式共用画布卡片、位置和缩放，专业内容集中在选中镜头后的编辑面板中。
- 专业面板展开完整提示词、台词、参考绑定和生成版本，并可直接切换镜头。内容修改后需重新通过。
- 首帧＋多参考增加“授权 AI 自动审核与重抽”。AI 助手审看下载的视频，满意后登记结论并接续下一镜。
  重抽次数用完仍不满意时记录剩余问题，使用最后完成视频的末帧继续。沿用每镜重抽上限和用户分镜批准。
- “反馈建议”入口增加常显文字、金色图标和边框，并适配深浅主题与窄屏。
- 修复页面新建项目缺少空分镜或审核文件时，助手无法写入分镜草稿的问题。
- 改善并行状态文件写入，AI 审核记录共用运行锁，避免并发覆盖。

## 使用说明

重新打开工作台后，在顶栏选择“专业”，点击镜头卡进入扩展编辑面板。
需要 AI 自动接续时，在首帧＋多参考的剧情设置中打开“授权 AI 自动审核与重抽”，通过分镜后在对话里说“开跑”。
AI 审核由当前 AI 助手实际审看视频并记录结论。生成结束后，仍在对话中要求助手关闭实例。
