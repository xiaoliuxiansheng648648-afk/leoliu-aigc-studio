# LeoLiu 工作台 1.0.4

本次新增“首帧＋多参考”工作流和几项优化，保留原有项目和素材。

## 首帧＋多参考：一镜接一镜

新建项目时选“首帧＋多参考”。第一镜从你给的首帧开始，后面每一镜从上一镜选用版的最后一帧开始，人物和声音照多参考保持一致，几镜接起来像一个长镜头。
这个模式下逐镜审核自动打开，不能关。每镜一圈：成片里点“选用此版”，下一镜点“更新为选用版末帧”，再点“通过此镜”，回到 AI 助手说“继续”。
此模式不自动关机，等待审核期间显卡实例仍在计费，完成或暂时不用时请在对话说“关机”。

## 其他优化

- 自动保存：误关页面后可以恢复，还没保存完就关闭会提醒。
- 上传素材可以多选，默认每个文件一个素材，也可以合并成同一素材的多个参考。
- 自动重抽的废片会显示在画布、成片列表和详情里，附重抽原因，可以预览对比。
- 切换视图不再跳回分镜；连接云端实例时，入口暂时拒绝会自动重连。

## 更新方式

- 已安装正式 1.0.1 或 1.0.3 的用户，让 AI 助手“检查工作台更新”，签名检查通过后自动更新至 1.0.4。
- 旧版未配置更新通道的用户，下载本目录的完整安装包重新安装。
- 原有项目、素材与成片继续保存在原项目目录。更新前若有生成任务，请先等任务结束。
