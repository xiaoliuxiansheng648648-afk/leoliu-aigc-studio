# LeoLiu 工作台 1.0.3

本次新增逐镜审核与文字反馈，保留原有项目和素材。

## 逐镜审核

在“剧情与设置”打开“逐镜审核”，默认关闭。开启后一次只生成一个镜头，完成后暂停。
在工作台点“选用此版”，再回到 AI 助手对话说“继续”，才生成下一镜。
不满意先重抽当前镜头，新成片需要重新选用。
此模式不自动关机，等待审核期间显卡实例仍在计费，完成或暂时不用时请在对话说“关机”。

## 优化反馈

点击右上角带加号的对话气泡图标，填写一段文字后提交。
只在主动提交时发送反馈文字、工作台版本与随机提交编号，不上传项目文件或连接凭据。
提交失败保留文字，确认收到后才清空。当前反馈入口使用 HTTP，请勿填写敏感信息。

## 更新方式

- 已安装正式 1.0.1 的用户，让 AI 助手“检查工作台更新”，签名检查通过后自动更新至 1.0.3。
- 旧版未配置更新通道的用户，下载本目录的完整安装包重新安装。
- 原有项目、素材与成片继续保存在原项目目录。更新前若有生成任务，请先等任务结束。
