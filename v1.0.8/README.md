# LeoLiu Studio 1.0.8

2026-11-16。抽卡、导入素材确认类别、提示词框可拉伸、反馈可附截图。

## 更新内容

- **抽卡**：每个镜头可以“抽卡 1 / 2 / 4 张”，同一提示词每张换一个种子，出来的版本都排在这一镜后面，挑满意的点“选用此版”。点抽卡就算通过这一镜。
  - 点了就排队，跟 AI 助手说“开抽”，由抽卡程序逐个生成；底部引导条显示“抽卡在线 / 正在抽 / 排队 N 张”。
  - 抽卡期间 GPU 不自动关机，不用时在对话里说“关机”。
  - 首帧＋多参考是一镜接一镜，暂不支持抽卡。
- **导入素材确认类别**：不再按照片长宽比猜类别。先看文件名（例如“人物”“背景”“道具”），认不出来就不猜；导入后弹出确认，每张点一下人物 / 场景 / 道具。素材详情里也能随时改类别。
- **专业模式提示词**：提示词框随内容长高，一次显示全文；下方有拖拽条可调高度；每段可以“放大编辑”。
- **反馈可附截图**：最多 3 张，可以选文件或直接粘贴。截图在本机先缩小，并去掉定位等信息再发送。
- 选中卡片的操作条在素材库或专业面板盖住画布时不再露出来。

## 使用说明

更新后重新打开工作台。想抽卡时，在镜头上点“抽卡”，再跟 AI 助手说“开抽”；不用了在对话里说“关机”。反馈截图前请遮住账号、地址等隐私。

## 安装与更新

首次安装请下载本目录的 `leoliu-studio-1.0.8.zip`，解压后交给 AI 助手安装。
已配置正式更新通道的用户，让 AI 助手“检查工作台更新”即可升级。
