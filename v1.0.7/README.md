# LeoLiu Studio 1.0.7

2026-11-16。“多参考 · 自然”免费开放，新增 8 步加速开关，画布更顺手。

## 更新内容

- 新增内置工作流“多参考 · 自然”，所有人都能用：
  - 在多参考的基础上加了皮肤细节和电影质感两个风格 LoRA，人物更像真实相机拍的；
  - 每镜自动加触发词，每镜种子各不相同，避免几镜构图一样；
  - 编译前会拦下两种常见问题：台词以外写了中文、相邻两镜景别写得一样；
  - 两个风格 LoRA 由实例按清单下载，不用自己准备。
- “剧情与设置”新增“8 步加速”勾选框，默认不勾：
  - 勾上后采样从 24 步减到 8 步，出片更快，GPU 计费更省；
  - 代价是细节、皮肤质感、参考图和音色的还原度会下降，勾选时页面会列出优缺点；
  - 四个工作流都能用。首帧＋多参考用的是融合模型，官方没有配套的加速模型，效果没有实测；
  - 加速模型（约 2 GB）只在第一次用到时下载到实例上。
- 画布：
  - 选中卡片后，上方浮出这张卡的操作条：通过 / 撤回、选用此版、编辑、聚焦、删除素材；
  - 左侧工具条新增小地图和快捷键说明，小地图可拖动定位，开关会记住；
  - 快捷键：F 全貌、M 小地图、1–4 跳步骤、+/− 缩放、0 回到 100%、? 打开说明；
  - 素材卡右侧的绑定口换成带“+”的圆钮，更容易拖到镜头上。

## 使用说明

更新后重新打开工作台，顶部会多出“多参考 · 自然”。8 步加速适合试剧情、构图、多抽几版；定稿、人脸特写、台词口型和人物相似度要紧的镜头建议关掉。已经出过片的镜头不会因为改了开关而重跑。

## 验证范围

本地自动测试、浏览器检查、正式签名校验已通过；“多参考 · 自然”的两个 LoRA 下载地址已实测可下载并核对散列。8 步加速与“多参考 · 自然”在真实 GPU 上的出片效果待实测。
