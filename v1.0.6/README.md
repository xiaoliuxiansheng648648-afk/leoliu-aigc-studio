# LeoLiu Studio 1.0.6

2026-11-15。分镜方法、本机扩展工作流与付费授权、仙宫云接口关机。

## 更新内容

- 写分镜前先读“分镜方法”：怎么切镜、怎么选时长、只写看得见的、镜头怎么接、写完冷读。
- 台词和镜头时长对不上时提醒（按每秒约 6 个字估算）。write-draft 和页面镜头卡都会提示，不拦写入。
- 支持本机扩展工作流：放在 `~/LeoLiuStudio/extensions/workflows/`，工作台更新不覆盖。
  - 扩展可以跑在实例上它自己的一套环境里，由扩展自己提交和取回，结果照常显示在画布上。
  - 扩展可以自带附加命令，用 `extension <工作流编号> <命令>` 运行，例如在实例上安装它的环境。
- 付费扩展工作流改为离线授权，不联网：
  - `license request` 生成申请码；
  - `license install` 安装授权包；
  - `license status` 查看授权状态。

  授权绑定这台电脑，可以是按期授权，也可以是永久授权。按期授权到期只停用该工作流，项目、素材、已出的视频和其他工作流都不受影响。
- 仙宫云实例改用平台接口“关机释放GPU”关机，查到“已关机”为止。大盘备份较慢，最长等 60 分钟。第一次使用前运行 `engine save-xgc-token` 保存访问令牌。
- draft-kit 给出的“提示词写法”改为该工作流自己的说明文件，扩展工作流不再指错位置。
- 引擎：按散列替换核心文件，保留已装的自定义节点；注册两个稳定的 T8 节点。

## 使用说明

更新后重新打开工作台。
用仙宫云的用户，第一次关机前先运行 `engine save-xgc-token`，在私密窗口粘贴控制台的访问令牌。令牌只存系统凭据库。
拿到付费工作流授权包的用户，让 AI 助手运行 `license install 授权包路径`，再运行 `open`。

## 验证范围

本地自动测试、隔离安装、授权安装预演与正式签名校验已通过。真实 GPU 生成和原生 Windows 环境需在对应环境实测。

## 安装与更新

首次安装请下载本目录的 `leoliu-studio-1.0.6.zip`，解压后交给 AI 助手安装。
已配置正式更新通道的用户，让 AI 助手“检查工作台更新”即可升级。
